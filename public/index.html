Download manager for Windows 10 and 11

An open-source download manager with a multi-connection HTTP/HTTPS engine, torrent support and a browser extension for Chrome, Edge and Brave. Windows 10/11, 64-bit.

Features

  • Multi-connection engineParallel ranged requests with automatic fallback to a single stream, resume and speed limits.
  • Torrent clientMagnet links and .torrent files, with sequential or rarest-first piece picking.
  • Browser integrationCaptures downloads and page media, with a video ribbon that offers the available qualities.
  • Schedule and queuePause, resume, reorder and schedule downloads; bulk import a list of URLs.
  • ThemesNine themes plus a custom accent colour, with a contrast-checked palette.
  • Verified updatesThe app checks for releases and verifies the installer SHA-256 before running it.

Browser extension

The extension is installed from the app, because Chrome does not allow silent installs of extensions that are not in the Web Store. Windows registrations and the native host are set up by the installer.

  1. Install N&T.
  2. Open the browser's extensions page (chrome://extensions, edge://extensions or brave://extensions) and turn on Developer mode.
  3. Choose Load unpacked and select extension\unpacked inside the install folder (default C:\Program Files\N&T).

Updates

The app checks this server first (GET /api/update) and falls back to GitHub releases. Update metadata, installer URLs and SHA-256 checksums are generated by build-installer.ps1 and published with wrangler deploy; see docs/CLOUDFLARE_UPDATES.md.
